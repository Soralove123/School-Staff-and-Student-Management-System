# School Staff and Student Management System

A teacher-student information management system designed for school teaching administration.  
The system provides centralized management of teachers, students, courses, and grades, helping improve the efficiency of data entry, query, modification, and maintenance.

## Features

- User login and authentication
- Role-based permission management
- Student information management
- Teacher information management
- Course management
- Grade management
- Data query and retrieval
- Add, edit, and delete records
- Structured database storage
- Graphical user interface

## Functional Modules

### Student Management
Supports the addition, modification, deletion, and query of student information.

### Teacher Management
Provides functions for maintaining and retrieving teacher information.

### Course Management
Manages course information and establishes relationships between teachers, students, and courses.

### Grade Management
Supports the recording, modification, and query of student grades.

### User Authentication
Different users can access corresponding system functions according to their permissions.

## System Design

The system uses object-oriented programming principles to organize different functional modules.

A database is used to store and manage information about:

- Students
- Teachers
- Courses
- Grades
- User accounts

Relationships between these data entities are established to achieve structured storage and efficient retrieval.
